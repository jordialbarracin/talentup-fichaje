General

¿Qué es TalentUP Fichaje?
TalentUP Fichaje es un SaaS de registro horario para hostelería y pequeños negocios. Combina un dispositivo hardware (ESP32 CYD con lector NFC) con una aplicación web para gestionar entradas, salidas, turnos y cumplimiento legal del RD-ley 8/2019. Los empleados fichan tocando su tarjeta NFC en el dispositivo; los datos se sincronizan automáticamente con el dashboard.
¿Cómo funciona el fichaje con NFC?
Cada empleado recibe una tarjeta NFC (o llavero NFC) asignada a su perfil. Al entrar o salir del trabajo, toca la tarjeta en el lector PN532 del dispositivo ESP32 CYD. La pantalla TFT muestra confirmación visual del fichaje (nombre, hora, tipo: entrada/salida). El dispositivo envía el registro al backend via WiFi en tiempo real. Si no hay conexión, guarda el fichaje en caché local (SPIFFS) y lo sincroniza cuando recupera conexión.
¿Qué pasa si no hay internet en el local?
El dispositivo ESP32 CYD funciona en modo offline. Los fichajes se guardan en la memoria flash interna (SPIFFS) con timestamp preciso. Cuando el dispositivo recupera conexión WiFi, sincroniza todos los fichajes pendientes con el backend. La capacidad de caché depende del plan: Starter (4h), Pro (24h), Enterprise (72h). En caso de corte prolongado, los fichajes no se pierden.
¿Puedo usar mi propio móvil para fichar?
El plan Pro y Enterprise incluyen fichaje vía PWA (Progressive Web App). El empleado puede fichar desde su móvil abriendo una URL en el navegador, sin instalar ninguna app. El fichaje móvil puede incluir geolocalización para verificar que el empleado está en el local. El plan Starter solo permite fichaje NFC con el dispositivo físico y fichaje web manual.
¿Cuánto tarda en estar operativo?
El setup completo toma menos de 30 minutos: crear la cuenta, configurar el tenant, dar de alta empleados, asignar tarjetas NFC y conectar el dispositivo ESP32 a WiFi. El dispositivo se provisiona via portal cautivo: se enciende, se conecta al WiFi del local, se vincula al tenant escaneando un QR desde el dashboard, y está listo. Las tarjetas NFC se asignan a empleados desde el panel web.
¿Necesito instalar algo en mi ordenador?
No. TalentUP Fichaje es 100% cloud. El dashboard se accede desde el navegador web (Chrome, Safari, Firefox, Edge). No hay software que instalar ni mantener. El único hardware es el dispositivo ESP32 CYD que se coloca en el local, normalmente junto a la entrada.

Hardware ESP32

¿Qué es el ESP32 CYD?
El ESP32 CYD (Cheap Yellow Display) es un microcontrolador ESP32 con pantalla TFT táctil de 2,8 pulgadas (320x240 px), basado en la librería TFT_eSPI. Es el corazón del dispositivo de fichaje. Incluye WiFi integrado, lector NFC PN532 conectado por I2C (pines IO22/IO27), reloj RTC para timestamps precisos, y memoria SPIFFS para caché offline.
¿Cómo se instala el ESP32 CYD?
Instalación simple: 1) Conectar el lector NFC PN532 al ESP32 via I2C (cables SDA a IO22, SCL a IO27). 2) Encender el dispositivo (USB-C 5V). 3) El dispositivo entra en modo configuración y muestra un portal cautivo WiFi. 4) Conectar el ESP32 al WiFi del local. 5) Escanear el QR de vinculación desde el dashboard de TalentUP. 6) El dispositivo se reinicia y queda operativo. Todo el proceso toma 5 minutos.
¿Necesito conocimientos técnicos para instalarlo?
No. El dispositivo viene pre-flasheado con el firmware de TalentUP. Solo necesitas: conectar el cable NFC (2 cables, sin soldadura, conexión por pines), enchufar a la corriente, y seguir el asistente de configuración en pantalla. El firmware (911 líneas, TFT_eSPI + PN532 + OTA + watchdog) ya está instalado. Las actualizaciones llegan por OTA (Over The Air) automáticamente.
¿La pantalla táctil funciona?
La pantalla TFT del CYD 2432S028 tiene capacidad táctil resistiva, pero en nuestra implementación el táctil no se utiliza para el fichaje (los empleados fichan con tarjeta NFC, que es más rápido e higiénico). La pantalla muestra información: nombre del empleado, hora, tipo de fichaje (entrada/salida), confirmación visual y estado de conexión. El táctil se reserva para menús de configuración avanzada.
¿Qué tarjetas NFC son compatibles?
El lector PN532 soporta: Mifare Classic 1K/4K, Mifare Ultralight, Mifare DESFire, y tarjetas NFC Forum Type 2. Cualquier tarjeta NFC estándar funciona. Incluimos 10 tarjetas NFC con cada dispositivo (formato tarjeta crédito o llavero). Las tarjetas se asignan a empleados desde el dashboard. Una tarjeta solo puede estar asignada a un empleado a la vez.
¿Qué pasa si se estropea el dispositivo?
El hardware tiene 2 años de garantía. Si el dispositivo falla, lo reemplazamos sin coste (envío nuevo dispositivo, devolución del defectuoso). Los fichajes en caché del dispositivo estropeado se recuperan si la memoria SPIFFS es legible. Si no, los fichajes ya sincronizados con el backend están seguros en la nube. El plan Enterprise incluye dispositivo de respaldo.
¿Puedo comprar el hardware por separado?
Sí. El BOM completo (ESP32 CYD + PN532 + carcasa) cuesta 131€. Puedes comprar unidades adicionales desde el dashboard. Si prefieres montar tu propio hardware, el firmware es open-source y compatible con cualquier ESP32 + TFT_eSPI + PN532. El BOM detallado está disponible en nuestro GitHub.

Legal / RD-ley 8/2019

¿Cumple TalentUP el RD-ley 8/2019?
Sí. Todos los planes cumplen el Real Decreto-ley 8/2019 de registro horario. El sistema registra hora exacta de entrada y salida de cada empleado, conserva los registros durante 4 años (requisito legal), y permite exportarlos en formato auditable (CSV/PDF con timestamp, empleado, tipo de fichaje). El registro es inmutable: una vez registrado un fichaje, no puede modificarse, solo anotarse correcciones con justificación.
¿Qué exige exactamente el RD-ley 8/2019?
El RD-ley 8/2019 exige que las empresas lleven un registro horario diario de la jornada laboral de cada empleado: hora de inicio y hora de fin. El registro debe conservarse durante 4 años y estar disponible para Inspección de Trabajo, sindicatos y empleados. No especifica el formato (puede ser papel o digital), pero el formato digital con timestamp inmutable es el más seguro frente a inspecciones.
¿Los registros son inmutables?
Sí. Una vez que un fichaje se registra (timestamp + empleado + tipo), el registro no puede modificarse ni borrarse. Si hay un error (el empleado fichó dos veces entrada), se puede añadir una corrección con justificación, pero el registro original se mantiene. Esto es deliberado: la Inspección de Trabajo puede exigir ver el registro原始 y cualquier alteración sería una infracción.
¿Quién puede acceder a los registros?
Los registros de fichaje están disponibles para: el empresario (via dashboard), el empleado (via su perfil, solo sus propios fichajes), la Inspección de Trabajo (previa solicitud) y los representantes legales de los trabajadores (sindicatos, previa solicitud). El acceso se gestiona por roles y permisos. El sistema cumple con el RGPD/LOPD en cuanto al tratamiento de datos personales.
¿Cuánto tiempo se conservan los datos?
Los registros de fichaje se conservan durante 4 años (requisito del RD-ley 8/2019). Los datos personales del empleado se conservan mientras el empleado esté activo y 90 días adicionales tras su baja. Tras la cancelación de la cuenta de TalentUP, los datos se conservan 90 días y luego se eliminan permanentemente. Puedes exportar todos tus datos en CSV antes de la eliminación.
¿TalentUP es compatible con convenios colectivos específicos?
TalentUP registra la jornada real trabajada (entradas y salidas). La interpretación de ese registro según el convenio colectivo aplicable (hostelería, comercio, etc.) corresponde a la empresa. El sistema calcula horas trabajadas, horas extra y excesos de jornada automáticamente, pero la aplicación de tablas salariales y compensaciones se gestiona externamente. La exportación a SIGLO (nóminas) está disponible en plan Pro y Enterprise.

Técnico / API

¿Tiene API?
Sí, API REST completa disponible en los planes Pro y Enterprise. Endpoints para: fichajes (GET, POST), empleados (CRUD), turnos (CRUD), reportes (GET), centros de trabajo (CRUD). Autenticación via Bearer token. Rate limiting: 100 requests/minuto (Pro), 1000/minuto (Enterprise). Documentación OpenAPI/Swagger disponible en /docs. Webhooks disponibles para integraciones en tiempo real.
¿Qué stack tecnológico usa?
Backend: FastAPI (Python 3.12) + SQLAlchemy + PostgreSQL (producción) / SQLite (desarrollo). Frontend: SPA vanilla JavaScript (sin framework, sin build step). Hardware: ESP32 (C++/Arduino, TFT_eSPI + PN532 I2C). Infraestructura: Railway (backend), Vercel (frontend, dominio talentup.es), GitHub Pages (duplicado). Observabilidad: Grafana. Pagos: Stripe. Tests: 202 tests automatizados.
¿Puedo integrar TalentUP con mi software de nóminas?
Sí. El plan Pro y Enterprise incluyen exportación a SIGLO (software de nóminas más usado en España) y exportación genérica CSV/Excel. Para integraciones custom con otros sistemas (Sage, NCS,etc.), el plan Enterprise incluye soporte para integración a medida via API y webhooks.
¿Los datos están seguros?
Los datos se transmiten via HTTPS (TLS 1.3). Las contraseñas se hashean con bcrypt. La base de datos PostgreSQL está en Railway con backups automáticos diarios y replicación. El acceso a la API requiere autenticación Bearer. Los fichajes son inmutables (append-only log). Cumplimos RGPD/LOPD. El plan Enterprise incluye cifrado a reposo y SSO (SAML/OAuth).
¿El firmware del ESP32 es open-source?
Sí. El firmware del ESP32 CYD (911 líneas, TFT_eSPI + PN532 + OTA + watchdog timer) es open-source y está disponible en nuestro GitHub. Puedes compilarlo y flashearlo tú mismo si prefieres usar hardware propio. Las actualizaciones OTA se envían automáticamente desde TalentUP, pero puedes optar por no actualizar (no recomendado, las actualizaciones incluyen parches de seguridad).
¿Puedo usar el sistema sin el hardware ESP32?
Sí. El plan Pro permite fichaje vía PWA móvil (sin hardware) y fichaje web manual. El plan Starter requiere el dispositivo NFC pero también incluye fichaje web de respaldo. El hardware ESP32 es la opción recomendada para hostelería porque el NFC es más rápido (1 segundo vs 10 segundos abriendo el móvil), más higiénico (sin tocar pantalla) y no requiere que el empleado tenga su propio móvil.
